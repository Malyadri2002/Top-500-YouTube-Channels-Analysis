# Top-500-YouTube-Channels-Analysis
•	Collected and cleaned data on the top 500 YouTube channels using web scraping and public datasets.
•	Analyzed trends in subscriber growth, video views, upload frequency, and content categories.
•	Created visualizations to showcase top-performing niches (e.g., gaming, education, music) and regional trends.
•	Identified key factors influencing channel popularity and engagement rates using correlation analysis.
•	Tools Used: Python (Pandas, Beautiful Soup, Seaborn), Excel.
